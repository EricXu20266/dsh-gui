# Bug 修复记录 — 2026-08-16

## 1. `biome` 依赖装错包
- **现象**：`pnpm exec biome check .` 实际调用的是 npm 上旧的 `biome` 环境变量工具，lint/format 完全失效。
- **根因**：包名写错；正确包名为 `@biomejs/biome`。
- **修复**：`package.json` 改为 `@biomejs/biome@1.9.4`，并补充 check/lint/format 脚本。

## 2. 首次安装完成后应用可能自行退出
- **现象**：向导窗口关闭 → `launchMain()` 异步启动 host 时，`window-all-closed` 无条件 `app.quit()`，存在竞态。
- **根因**：退出事件监听重复，且未区分「向导关闭后的自动启动」与「用户主动退出」。
- **修复**：合并生命周期监听；`before-quit` 置 `isQuitting` 并统一清理；`window-all-closed` 仅在显式退出或确实无窗口/无启动任务时退出。

## 3. host 固定 3080 端口冲突
- **现象**：已有 DHS web 或其他进程占用 3080 时，GUI 可能加载到别人的服务。
- **根因**：`waitForPort(3080)` 只能证明端口可连，不能证明是自己的 host。
- **修复**：`dsh web --port 0` 动态端口 + 解析 stdout URL + 单实例锁。

## 4. 内置插件少装 2 个
- **现象**：README 宣称 5 个插件自动注册，实际只装 discovery/skillmanager/mcpmanager。
- **修复**：`installer.ts` 列表补 `dsh-proxy` 与 `dsh-about`。

## 5. 打包版向 `.app/Resources` 写依赖
- **现象**：macOS 首次安装可能在只读/签名目录中失败。
- **修复**：resources/dhs 作为种子复制到 `userData/dhs` 后安装。

## 6. 开发态 DHS 路径硬编码
- **现象**：`E:/AllinDeepSeek/deepseek-harness` 只在本机有效。
- **修复**：改为 `join(app.getAppPath(), '..', 'deepseek-harness')`，并保留 `DSH_ROOT` 覆盖。

## 7. pnpm install 报 ERR_PNPM_INVALID_VERSION_UNION
- **现象**：`allowBuilds` 中的 `'@deepseek-ai/dsh-subprocess-local@file:../deepseek-harness/...'` 被 pnpm 11 判定为非法版本联合。
- **根因**：pnpm 11 的 `allowBuilds` 只接受裸包名或 `name@精确版本`，不接受 `name@file:` 形式。
- **修复**：`pnpm-workspace.yaml` 改为 `'@deepseek-ai/dsh-subprocess-local': true`。
